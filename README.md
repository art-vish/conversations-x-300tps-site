# Conversations × «300 токенов в секунду»

**[Открыть галерею карточек](https://art-vish.github.io/conversations-x-300tps-site/)**

18 редакционных и визуальных вариантов по выпуску подкаста с Валерием Ковальским, Сергеем Нотевским и Артёмом Вишней:

- A — «Кэш = деньги».
- B — «Модели без иллюзий».
- C — «Агенты и продакшен».

В галерее можно увеличить карточки, выбрать понравившиеся, оставить заметки и скачать отбор в JSON. Выбор сохраняется только в вашем браузере; для передачи отзыва скачайте файл и отправьте его команде привычным способом.

[Смотреть выпуск](https://www.youtube.com/watch?v=5IooP1bzF7Y)

Каталог `site/` обновляется автоматически из редакционного проекта. Он содержит публичные тексты, изображения и интерфейс. Правки публикации выполняются в исходном рабочем проекте, после чего собирается новая версия галереи.

Статус карточек — варианты для отбора и доработки. Подпись Conversations × 300 — предложенный вариант совместного оформления.
